Call Amazon Connect from your browser

A short test of a browser call to Amazon Connect. You will hear a synthesized greeting, then the call is designed to end. This is a demo for team members using simulated calls only.

What will happen

  1. Call controls appear in the lower right of this page once the Amazon Connect widget loads. If they don’t appear, see the status above.
  2. Use the call controls to start the call. Your browser asks to use the microphone: choose Allow. Nothing is called when this page opens.
  3. Listen for: Team Eleven. Your browser is connected to Amazon Connect. The call is designed to end after the greeting.

This page never shows a “connected” state of its own. The greeting is synthesized speech, not a recording. Hearing it shows audio playing from Amazon Connect to you; it does not show that your voice reached Amazon Connect.

Microphone

Checking microphone permission…

Blocked, or no prompt appeared?
  • Chrome or Edge: choose the site-settings icon left of the address bar, set Microphone to Allow, then reload this page and try again.
  • Firefox: choose the permissions icon left of the address bar, remove the blocked microphone entry, then reload and try again.
  • Safari: Safari → Settings → Websites → Microphone, set this site to Allow, then reload.
  • Connected but silent? Check that this tab is not muted and that your output device and volume are right.

Hang up

Use the widget’s hang-up control to end the call. Closing or minimizing the widget may not end it. The call is designed to disconnect after the greeting: for the acceptance test, let it finish by itself, then press hang-up if it is still connected.

To try again, start a new call from the widget. If it refuses, reload this page first.
